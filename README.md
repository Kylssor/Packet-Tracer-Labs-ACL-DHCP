# Packet-Tracer-Labs-ACL-DHCP
mplementación de ACL extendidas para permitir/bloquear servicios (FTP, SSH) y controlar ICMP (ping) entre redes/routers según reglas por IP.  Configuración de DHCP para asignación automática de direcciones IP a equipos finales y validación de conectividad/restricciones con pruebas.
