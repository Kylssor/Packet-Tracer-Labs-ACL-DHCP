# Packet Tracer Labs (Cisco)

Prácticas académicas de redes en Cisco Packet Tracer orientadas a soporte y operación de infraestructura.

## Qué se practica
- ACL extendidas para controlar tráfico entre redes/routers por IP y servicio
- Permitir/bloquear FTP y SSH según requerimientos
- Control de ICMP (ping) entre segmentos
- DHCP para asignación automática de IP a equipos finales
- Verificación de conectividad y restricciones mediante pruebas

## Cómo se valida
- Ping/ICMP entre hosts seleccionados
- Acceso a servicios permitidos (y bloqueo de servicios restringidos)
- Asignación correcta de IP por DHCP
